## 🎯 Common Tasks

### Change Colors
Edit `tailwind.config.js`:
```js
theme: { colors: { primary: '#your-color' } }
```

### Add Logo
Edit `ChatBot.jsx` header (replace emoji)

### Connect Backend
Edit `ChatBot.jsx` - use `sendMessage()` from `services/apiService.js`

### Deploy
```bash
npm run build        # Creates dist/
npm run preview      # Test locally
# Upload dist/ to any web host
```

## 💬 FAQs

**Q: Can I use this in production?**  
A: Yes! It's production-ready right now.

**Q: How do I connect to my backend?**  
A: Edit `services/apiService.js` and `ChatBot.jsx` to call your API.

**Q: Can I customize the colors?**
